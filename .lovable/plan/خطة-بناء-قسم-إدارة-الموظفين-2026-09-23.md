# خطة بناء قسم إدارة الموظفين

## النتيجة
صفحة موظفين عربية كاملة ومتجاوبة، تعرض البيانات الفعلية، وتدعم البحث والفلترة والإضافة عبر نموذج من ثلاث خطوات، مع الحفاظ على الهوية الزرقاء البيضاء الحالية.

## الواجهة
- رأس الصفحة بعنوان «إدارة الموظفين» وزر «إضافة موظف جديد» حسب صلاحية المستخدم.
- شريط بحث بالاسم أو الرقم الوظيفي، وفلاتر للقسم والحالة ونوع الدوام.
- عرض جدولي قابل للتمرير على الشاشات الضيقة، مع صورة رمزية، الحالة، وقائمة إجراءات.
- قائمة الإجراءات تدعم عرض الملف، التعديل، والحذف؛ الحذف يبقى للمدير فقط وفق الصلاحيات الحالية.
- نافذة إضافة من ثلاث خطوات: وظيفية، شخصية، ومالية، مع مؤشر تقدم وتنقل واضح.
- استخدام منتقي التاريخ العربي الحالي، ورسالة نجاح داخل الصفحة، وتحديث القائمة فور الحفظ.

## البيانات والصلاحيات
- توسيع سجل الموظف بالرقم الوظيفي، البريد العملي، الاسم الإنجليزي، المدير المباشر، نوع الدوام، الهوية، الميلاد، الجنسية والجنس.
- إبقاء البيانات المالية في جدول الرواتب المحمي للمدير، مع إضافة بدل السكن وبدل المواصلات وIBAN وربطها بسجل الموظف.
- المدير يرى كل الفروع ويحفظ البيانات المالية؛ المشغّل يضيف ويعدّل موظفي فرعه فقط دون الاطلاع على الرواتب؛ المشاهد للقراءة فقط.
- إضافة خمسة سجلات تجريبية قابلة لإعادة التشغيل بأمان، مع فرع رئيسي عند عدم وجود فرع.
- عدم تغيير منطق RLS الحالي؛ الإضافات تتبع السياسات الموجودة وتمنع أي كشف للبيانات المالية لغير المدير.

## التفاصيل التقنية
- إنشاء migration جديدة مرتبة تضيف الأعمدة والفهارس والتحققات وبيانات العرض التجريبية، مع تحديث الملف المرجعي المجمّع.
- ربط الصفحة مباشرة ببيانات Lovable Cloud، مع جلب الفروع والمديرين المتاحين حسب صلاحية الجلسة.
- حفظ الموظف أولاً، ثم إنشاء سجل الراتب للمدير فقط؛ عند فشل الجزء المالي تُعرض رسالة دقيقة دون إخفاء نجاح إنشاء الموظف.
- التحقق من البناء، ثم اختبار البحث والفلاتر وفتح النموذج والتنقل بين الخطوات على مقاس الهاتف.

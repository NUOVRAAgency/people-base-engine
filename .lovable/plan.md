# شاشة الإجازات الزجاجية للهاتف

## النطاق
- تحويل شاشة الإجازات إلى واجهة عربية RTL داكنة وهادئة، بخلفية متدرجة خفيفة وبطاقات وشريط فلترة ونموذج بإحساس زجاجي موحّد.
- إنشاء أنماط زجاجية دلالية قابلة لإعادة الاستخدام لاحقاً في بقية الأقسام، مع إبقاء الألوان محصورة في مؤشرات الحالة والإجراءات الضرورية.
- عرض طلبات الإجازات الفعلية حسب سياسات الدور والفرع الحالية، مع حالات تحميل وفراغ وأخطاء واضحة وغير مزعجة.

## الواجهة والتفاعل
- شريط فلترة بأربع حالات: الكل، معلّق، معتمد، مرفوض، مع عدّاد اختياري داخل كل تبويب.
- بطاقات طلبات تعرض اسم الموظف للمدير فقط، ونوع الإجازة، والفترة، وشارة حالة صغيرة، وخط جانبي بلون الحالة.
- زر إضافة دائري أعلى الشاشة للمدير والمشغّل فقط؛ لا يظهر للمشاهد.
- نموذج زجاجي لإضافة الطلب: الموظف، النوع، البداية، النهاية، مع التحقق من ترتيب التاريخين والحفظ دائماً بحالة معلّق.
- أزرار اعتماد ورفض للمدير فقط وعلى الطلبات المعلّقة فقط، مع تحديث القائمة والتنبيهات بعد الإجراء.

## التنفيذ التقني
- القراءة والكتابة مباشرة عبر العميل الحالي كي تُطبّق سياسات RLS الموجودة حسب المستخدم وفرعه.
- جلب قائمة الموظفين المتاحة للمستخدم من جدول الموظفين؛ سياسات الفروع الحالية تحدد الخيارات تلقائياً.
- عدم إضافة أو تعديل أي منطق للحضور أو الرواتب.
- استخدام عناصر الواجهة الموحدة الحالية، وإضافة رموز ألوان وظلال زجاجية في ملف التصميم العام بدلاً من ألوان ثابتة داخل الصفحة.

## التحقق
- فحص البناء والأخطاء.
- معاينة الشاشة على عرض هاتف ضيق وعرض هاتف أكبر.
- اختبار الفلترة، فتح النموذج، التحقق من التواريخ، والإرسال.
- التأكد من اختلاف الأزرار والبيانات الظاهرة حسب admin / operator / viewer بقدر ما تسمح جلسة الاختبار.
